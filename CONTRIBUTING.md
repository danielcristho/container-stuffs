# Contributing to Container Stuffs

Hi folks! 👋  
Thanks for your interest in contributing to **Container Stuffs** - a community-driven collection of container-based experiments and labs.

We welcome all kinds of contributions:  
new labs, bug fixes, documentation, discussions, or ideas for improvement.  
This guide will help you get started.

---

## Project Description

Container Stuffs is designed as an **open playground for learning and exploring container technologies**, covering everything from:

- Single-node Docker & Compose setups
- Multi-node or orchestrated environments (Swarm, Kubernetes, k3d)
- Advanced container use cases (security, CI/CD, observability, MLOps)

Each lab is:

- Self contained
- Minimal but meaningful
- Well-documented with a short README

---

## How to Contribute

### 1. Fork the Repository

Click the **Fork** button on the top right of this repo, then clone your fork:

```bash
git clone https://github.com/<your-username>/container-stuffs.git
cd container-stuffs
```
